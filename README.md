# 🌸 StayPink - Airbnb Clone

A full stack property rental web application built with the MERN stack, inspired by Airbnb. Features a beautiful baby pink theme with complete user authentication, property listings, image uploads, and booking management.

## ✨ Features
- 🔐 User Authentication (Signup / Login / Logout)
- 🏡 Browse property listings with search and category filters
- 📸 Add listings with image upload (via Cloudinary)
- 📋 Detailed listing pages with booking form
- 📅 Booking system with date selection and price calculation
- 👤 Personal dashboard to manage listings and bookings

## 🛠️ Tech Stack
| Layer | Technology |
|-------|-----------|
| Frontend | React.js, Tailwind CSS |
| Backend | Node.js, Express.js |
| Database | MongoDB Atlas |
| Image Storage | Cloudinary |
| Authentication | JWT, bcryptjs |
| Deployment | Netlify (frontend), Render (backend) |

## 🚀 Getting Started Locally

### Prerequisites
- Node.js installed
- MongoDB Atlas account
- Cloudinary account

### Installation

```bash
# Clone the repo
git clone https://github.com/zainab-nayeem/airbnb-clone.git
cd airbnb-clone

# Install backend dependencies
cd server
npm install

# Install frontend dependencies
cd ../client
npm install
```

### Environment Variables
Create a `.env` file in the `/server` folder:# airbnb-clone
StayPink - Airbnb Clone MERN Stack

### Run the App
```bash
# Terminal 1 - Backend
cd server
npm run dev

# Terminal 2 - Frontend
cd client
npm start
```
